# usg-setlist-analysis
# UNISON SQUARE GARDEN セットリスト・データセット & アソシエーション分析

## 1. データの出典
- 出典元: [setlist.fm](https://www.setlist.fm/)[cite: 1]
- 手法: setlist.fm REST API (v1.0) を使用した自動収集[cite: 1]
- 特徴: サーバー負荷を考慮し、スクレイピングではなく公式APIを介してMusicBrainz IDに基づく確実なデータ巡回を実装。[cite: 1]

## 2. 内容概要
日本のロックバンド「UNISON SQUARE GARDEN」の結成当時から2025年最新ライブに至るまでのセットリストデータを網羅したデータセットです。[cite: 1]
- **総公演数**: 1,089公演[cite: 1]
- **総ツアー数**: 41ツアー（ワンマン対象、フェス等除く）[cite: 1]
- **取得したデータ数**: 15,897件（楽曲演奏単位）[cite: 1]
- **項目**: 公演日、ツアー名、会場名、都市、演奏順、曲名[cite: 1]
- **形式**: CSV形式（UTF-8-sig）[cite: 1]

## 3. 分析の目的と手法（アソシエーション分析）
ライブにおけるセットリストは、アーティストの演出意図が最も反映される場所です。[cite: 1] 本プロジェクトでは、1.5万行を超えるデータに対し**アソシエーション分析（条件付き確率および時系列シーケンスの抽出）**を適用し、バンドが20年間で培った「選曲の哲学」と「繋ぎの黄金律」を定量化しました。[cite: 1]

特定のロングツアーによる局所的な偏りを排除するため、**「公演数ベース」と「ツアー数ベース」の2つのレイヤー**で集計・比較を行っています。[cite: 1]

## 4. 展開したコード一覧
リポジトリには、データ収集から多角的な分析・可視化を行う以下のPythonスクリプトが含まれています。[cite: 1]
※環境依存（Python 3.6等の旧環境）による画像ライブラリ等のビルドエラーを回避するため、分析ロジックはPandasの集計ロジックを用いてネイティブ実装しています。[cite: 1]

- `usg_full_master.py` : setlist.fm APIから各公演のセットリストデータを自動収集するスクリプト（要APIキー）。[cite: 1]
- `run_comprehensive_analysis.py` : 1,089公演・41ツアーを対象に、「ライブ内共演率」と「直後の繋ぎ（連番）」を全自動で算出し、サマリーCSVを出力するスクリプト。[cite: 1]
- `generate_poster_charts.py` : アソシエーション分析、共起ネットワーク、k-meansクラスタリング、ツアー形態別構成比率の4手法による可視化を行い、発表用グラフ画像を自動生成・保存するスクリプト。[cite: 1]
- `get_lyrics.py` : 歌ネットから各楽曲の歌詞テキストおよび対応ページURLを自動収集・取得するスクリプト。[cite: 2]
- `get_spotify_data.py` : MusicBrainz REST APIから全楽曲の詳細メタデータ（演奏時間、初出アルバム、リリース日、ISRCコード等）を一括取得するスクリプト。[cite: 3]
- `get_youtube_stats.py` : YouTube Data API (v3) を使用して公式チャンネルから全楽曲のMVおよびライブ映像の再生数・高評価数・コメント数等の統計データを取得・照合するスクリプト。[cite: 4]

## 5. 出力物一覧
プロジェクトの各種スクリプト実行によって生成・出力されるデータファイルおよび視覚化結果の概要です。

### CSVデータファイル
- `usg_full_master_japanese.csv` : 全1,089公演・15,897件の演奏データおよびツアー・会場情報を含む日本語化マスターデータセット。[cite: 1, 2, 3, 4]
- `usg_analysis_pair_summary.csv` : 同一ライブ内における楽曲同士の併発・共演確率（アソシエーションルール）をまとめた集計ファイル。[cite: 1]
- `usg_analysis_flow_summary.csv` : 「曲Aの直後に曲Bが演奏される」という時系列の繋ぎ・曲順の統計ファイル。[cite: 1]
- `usg_lyrics.csv` : 全楽曲の歌詞本文、歌ネット上の表記タイトル、対応URLを格納した歌詞データセット。[cite: 2]
- `usg_features.csv` : 各楽曲の演奏時間（秒）、初出アルバム名、リリース日、リリース種別（Primary Type）、ISRCコード、MBIDなどの音楽構造メタデータ。[cite: 3]
- `usg_youtube_stats.csv` : 各楽曲の公式MVおよびライブ映像のタイトル、再生回数、高評価数、コメント数、公開日、動画URLをまとめた人気指標データセット。[cite: 4]

### 分析・可視化画像（ポスター発表用チャート）
- `poster_fig1_association.png` : 【手法1】ツアー単位でのセットリスト併発ルール（リフト値・併発率Top10）の水平バーチャート。[cite: 1]
- `poster_fig2_network.png` : 【手法2】主要25楽曲のライブセットリスト内における共起関係を表すネットワークグラフ。[cite: 1]
- `poster_fig3_kmeans.png` : 【手法3】YouTube再生回数（対数）と通算演奏回数を軸としたk-meansクラスタリングによる楽曲役割分類散布図。[cite: 1]
- `poster_fig4_tour_composition.png` : 【手法4】ライブ形態（周年・ベストツアー / アルバムツアー / フェス等）ごとの楽曲タイプ構成比率（100%積み上げ棒グラフ）。[cite: 1]

## 6. 今後の展望（追加データの提案）
現状の「曲名」のテキスト・時系列データに加え、**Spotify Web API** から取得できる楽曲の特徴量メタデータ（BPM、Energy、Valenceなど）を結合するフェーズを進めています。[cite: 1]
これにより、単なる演奏回数を超えて「ライブ全体の盛り上がり（熱量）のグラデーション」や、「ツアーコンセプトの音楽的変遷」をクラスター分析等で可視化することを目指します。[cite: 1]
