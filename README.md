
# usg-setlist-analysis
# UNISON SQUARE GARDEN セットリスト・データセット & アソシエーション分析

## 1. データの出典
- 出典元: [setlist.fm](https://www.setlist.fm/)
- 手法: setlist.fm REST API (v1.0) を使用した自動収集
- 特徴: サーバー負荷を考慮し、スクレイピングではなく公式APIを介してMusicBrainz IDに基づく確実なデータ巡回を実装。

## 2. 内容概要
日本のロックバンド「UNISON SQUARE GARDEN」の結成当時から2025年最新ライブに至るまでのセットリストデータを網羅したデータセットです。
- **総公演数**: 1,089公演
- **総ツアー数**: 41ツアー（ワンマン対象、フェス等除く）
- **取得したデータ数**: 15,897件（楽曲演奏単位）
- **項目**: 公演日、ツアー名、会場名、都市、演奏順、曲名
- **形式**: CSV形式（UTF-8-sig）

## 3. 分析の目的と手法（アソシエーション分析）
ライブにおけるセットリストは、アーティストの演出意図が最も反映される場所です。本プロジェクトでは、1.5万行を超えるデータに対し**アソシエーション分析（条件付き確率および時系列シーケンスの抽出）**を適用し、バンドが20年間で培った「選曲の哲学」と「繋ぎの黄金律」を定量化しました。

特定のロングツアーによる局所的な偏りを排除するため、**「公演数ベース」と「ツアー数ベース」の2つのレイヤー**で集計・比較を行っています。

## 4. 展開したコード一覧
リポジトリには、データ収集から多角的な分析までを行う以下のPythonスクリプトが含まれています。
※環境依存（Python 3.6等の旧環境）による画像ライブラリ等のビルドエラーを回避するため、分析ロジックはPandasの集計ロジックを用いてネイティブ実装しています。

- `usg_full_master.py` : setlist.fm APIからデータを自動収集するスクリプト（要APIキー）
- - `usg_full_master.py`  （各公演のセットリスト）
- `run_comprehensive_analysis.py` : 1,089公演・41ツアーを対象に、「ライブ内共演率」と「直後の繋ぎ（連番）」を全自動で算出し、以下のサマリーCSVを出力するスクリプト。
- - `usg_analysis_pair_summary.csv`（同一ライブ内ペアの統計）
- - `usg_analysis_flow_summary.csv`（直後の繋ぎ・曲順の統計）

## 5. 今後の展望（追加データの提案）
現状の「曲名」のテキスト・時系列データに加え、**Spotify Web API** から取得できる楽曲の特徴量メタデータ（BPM、Energy、Valenceなど）を結合するフェーズを進めています。
これにより、単なる演奏回数を超えて「ライブ全体の盛り上がり（熱量）のグラデーション」や、「ツアーコンセプトの音楽的変遷」をクラスター分析等で可視化することを目指します。
